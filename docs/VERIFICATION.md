## Running result
The final application is running through Docker Compose at **http://localhost:5080**, backed by **Microsoft SQL Server 2022** in a persistent local Docker volume. SQL Server was tested using linux/amd64 emulation on this Apple Silicon machine. The separate temporary dotnet verification servers were stopped.

Stop without deleting data: `docker compose stop`. Restart: `docker compose up -d`. If changing source, rebuild using `docker compose up --build -d`.

## Explicit limits
- No public/cloud host was provisioned. Cloud deployment remains an external account/configuration task.
- No GitHub push was performed; the owner explicitly requested local commits and will push manually.

- SQL schema export was generated from EF Core; existing-database upgrade migrations are not implemented.
- The local Docker stack uses Development with synthetic accounts and is bound to loopback. It is not the supplied configuration for a public hospital deployment.
